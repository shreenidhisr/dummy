# Remotion — Graph Representation

Animated walkthrough of the **two** common graph representations:

1. Sample graph build  
2. Adjacency list  
3. Adjacency matrix  
4. Differences (list vs matrix)  
5. Java code for both  

## Quick start

```bash
cd remotion-graph
npm install
npm run dev
```

Composition: `GraphRepresentation`

## Render

```bash
npm run render
```
